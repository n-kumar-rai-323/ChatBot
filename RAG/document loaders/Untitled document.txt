What is LLM
An LLM (Large Language Model) is a type of artificial intelligence (AI) designed to understand, process, and generate human-like text. Trained on vast amounts of data—such as books, articles, and websites—these models learn the patterns and relationships between words to perform tasks like answering questions, translating languages, and writing code. 
How it Works
* Transformer Architecture: LLMs rely on deep learning, utilizing a specialized architecture that processes words in relation to one another to understand context.
* Pattern Prediction: Rather than "thinking," they work by predicting what word should come next in a sentence based on the context of the words that came before it.
* Massive Scale: The "large" in LLM refers to the billions of data parameters and vast computational power used during training, allowing the AI to grasp complex topics and nuances. 
Common Use Cases
* Content Generation: Drafting emails, essays, blogs, or creating creative writing.
* Summarization: Condensing long documents, articles, or transcripts into quick, easy-to-read points.
* Coding Assistance: Writing, debugging, and explaining programming code.
* Conversational AI: Powering chatbots and virtual assistants for customer service or general inquiries. 
Real-World Examples
* ChatGPT: Developed by OpenAI.
* Gemini: Developed by Google.
* Claude: Developed by Anthropic. 
Limitations
While highly capable, LLMs do not possess human reasoning, common sense, or real-world consciousness. Because they predict probabilities, they can sometimes produce incorrect, biased, or completely fabricated information (known as an AI "hallucination").

What is a Prompt?
A prompt is the input or instruction you give to an AI model to get a response.
Types of prompts 
🔹 1. Simple Prompt
A simple prompt is a direct, single instruction or question to the AI.
✔ Example:
“What is Python?”
or
“Explain REST API.”
📌 Key idea:
* No structure
* No role or format
* Just a direct request
⚡ Use case:
* Quick answers
* Basic Q&A
* Casual usage
________________


🔹 2. System + User Prompt
This is a two-layer prompt system used in real AI applications.
✔ System Prompt (rules/behavior)
Defines how the AI should behave.
Example:
“You are a helpful coding assistant. Always explain in simple terms.”
________________


✔ User Prompt (task/input)
What the user actually asks.
Example:
“Explain Django authentication.”
________________

* Keeps conversation context

This is memory within a single chat session.

3. Context Window Memory
This is the temporary memory limit of LLMs.
✔ Example:

* Older messages are trimmed or summarized
📌 Key point:
* Built into the model
* Not permanent storage

* Retrieve similar memory when needed

This is what AI uses while thinking step-by-step.

Embedding 
Embedding models are machine learning algorithms that translate unstructured data—such as text, images, and audio—into numerical arrays called vectors. By doing so, they map data into a multi-dimensional space where items with similar meanings are positioned close to each other, allowing computers to understand context and semantics.
They are the foundational engine behind semantic search, Retrieval-Augmented Generation (RAG), and recommendation engines.
How They Work
* Vectorization: Raw data is encoded into high-dimensional vectors (arrays of numbers). 
* Semantic Capture: Unlike traditional keyword matching, these numbers capture the underlying meaning, tone, and relationships between concepts.
* Similarity Scoring: AI systems compare these vectors using mathematical metrics (like Cosine Similarity or Euclidean Distance) to find the most relevant matches for a query.
